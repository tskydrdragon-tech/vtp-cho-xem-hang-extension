Một Extension nhỏ gọn giúp tự động thay đổi dòng chữ "KHÔNG XEM HÀNG" thành "CHO XEM HÀNG" trên tất cả các giao diện in đơn A5, A6, A7 của bên vận chuyển ViettelPost. Giúp chủ shop tiết kiệm thời gian chỉnh sửa thủ công và tăng trải nghiệm mua sắm cho khách hàng.

Hướng dẫn cài đặt nhanh:
1. Tải file Sửa ViettelPost.zip trong thư mục này về máy tính và giải nén.
2. Mở trình duyệt (Chrome/Edge/Cốc Cốc) -> Truy cập trang quản lý Tiện ích mở rộng (Extensions).
3. Bật "Chế độ dành cho nhà phát triển" (Developer mode).
4. Bấm "Tải tiện ích đã giải nén" (Load unpacked) và chọn thư mục chứa code.
5. F5 lại trang in đơn ViettelPost để hưởng thụ thành quả!
